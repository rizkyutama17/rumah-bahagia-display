# Rumah Bahagia Display

TV dashboard untuk rumah pribadi: jam, jadwal sholat (Kemenag via MyQuran API), cuaca & kualitas udara Palembang (Open-Meteo), dengan Adzan Mode otomatis.

Dibuka di browser TV/laptop: cukup buka `index.html`.

## Fitur
- Jadwal sholat harian Kota Palembang (kode lokasi 0816) dari [api.myquran.com](https://api.myquran.com) — cache offline bila internet mati
- Cuaca + AQI live dari Open-Meteo
- Adzan Mode otomatis: adzan → jeda 5 menit → menunggu iqamah → iqamah
- Tanggal Masehi + Hijriah otomatis

## Lisensi
Pribadi. Silakan pakai pola serupa untuk kebutuhan sendiri.
